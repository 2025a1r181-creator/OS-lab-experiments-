# Experiment 1: Installation and Configuration of Oracle VirtualBox and Ubuntu Linux

### 🎯 Objective
To install Oracle VirtualBox, create and configure a virtual machine, and deploy the Ubuntu Linux operating system in a virtualized environment.

### 🛠️ Step-by-Step Procedure
1. **Download:** Downloaded Oracle VirtualBox and the Ubuntu ISO file.
2. **VM Creation:** Opened VirtualBox, created a new Virtual Machine, allocated RAM, and created a Virtual Hard Disk (VDI).
3. **Storage Settings:** Mounted the Ubuntu ISO in the Optical Drive settings.
4. **Installation:** Started the VM and followed the Ubuntu on-screen setup prompts for language, user credentials, and installation type.
5. **Post-Installation:** Completed the setup and successfully booted into the Ubuntu Desktop.
